# Ollama

Ollama is a large language model that can be run locally on various platforms, including Linux, macOS, and Windows. It allows users to interact with the model through a web interface or command-line interface. Ollama supports multiple models, including Llama 3.3, DeepSeek-R1, Phi-4, Gemma 3, and others. Users can download and install Ollama using a one-command script or manually by following instructions on the official website.
