# InvokeAI

InvokeAI is a leading creative engine for Stable Diffusion models that empowers professionals and enthusiasts to generate and create visual media using the latest AI-driven technologies. It offers an industry-leading WebUI and serves as the foundation for multiple commercial products. InvokeAI allows users to train models on their intellectual property, control every aspect of the production process, and maintain complete ownership of their data in perpetuity.
