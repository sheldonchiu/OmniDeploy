# Stable Diffusion Fooocus

Fooocus is a free and open-source AI image generator based on Stable Diffusion. It attempts to combine the best of Stable Diffusion and Midjourney: open source, offline, free, and ease-of-use. Fooocus has optimized the Stable Diffusion pipeline to deliver excellent images. It provides a user-friendly interface for generating high-quality images using text prompts.
