# Cloudflare Tunnel

Cloudflare Tunnel is a secure way to connect your resources to Cloudflare without a publicly routable IP address. It provides a lightweight daemon in your infrastructure (cloudflared) that creates outbound-only connections to Cloudflare's network, allowing you to access private applications and services securely. With Cloudflare Tunnel, you can enable clientless access to your applications by creating public hostname routes, which route traffic to specific addresses, protocols, and ports associated with private applications.
